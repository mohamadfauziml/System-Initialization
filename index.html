Your Bootcamp Assignment

You have joined a Python development team as a Junior Python Developer. Before you can complete your first client project, you must pass four system-training missions. Each mission develops a different programming skill, beginning with data storage and ending with the construction of a complete Python program.

Complete the missions in the recommended order so that each new challenge builds on the skills developed in the previous mission.

Understand → Apply → Repair → Build

What You Will Learn

Outcome 1

Understand Variables

Explain how Python stores data using variables.

You will identify how values are assigned and stored.

Outcome 2

Name Variables Correctly

Apply Python variable-naming rules correctly.

You will inspect, repair, and justify variable names.

Outcome 3

Write Simple Programs

Use correct Python syntax to write simple programs.

You will repair syntax and build a working program from a client request.

How to Complete the Bootcamp

  1. Start with Mission 1.
  2. Complete each mission in the recommended order.
  3. Read the explanatory feedback after every decision.
  4. Use hints only when needed.
  5. Complete the reflection task at the end of each mission.
  6. Return to this portal after finishing each game.
  7. Continue to the next mission card.
